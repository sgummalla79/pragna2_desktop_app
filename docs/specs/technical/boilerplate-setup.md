## 1. Overview

Scaffold a Tauri 2 desktop application using `create-tauri-app` (react-ts template) and extend it with a Clean Architecture module structure in the Rust backend. No custom business logic is introduced at this stage.

## 2. Architecture & Layer Placement

- **Domain** (`src-tauri/src/domain/mod.rs`): Empty stub — no entities yet.
- **Application** (`src-tauri/src/application/mod.rs`): Empty stub — no use cases yet.
- **Adapters** (`src-tauri/src/adapters/mod.rs`): Empty stub — the generated `greet` Tauri command lives in `lib.rs` temporarily until the first real feature moves it into this layer.

## 3. Data Flow

```
React (src/App.tsx)
  → invoke("greet", { name })          [Tauri IPC]
  → lib.rs::greet(name: &str)          [Tauri command — adapter]
  → returns String to frontend
```

## 4. Module & File Layout

```
src/                        ← React + TypeScript (Vite)
  main.tsx                  ← React entry point
  App.tsx                   ← Root component with greet demo
  App.css / styles.css
src-tauri/
  src/
    domain/mod.rs           ← layer stub
    application/mod.rs      ← layer stub
    adapters/mod.rs         ← layer stub
    lib.rs                  ← mod declarations + Tauri builder + greet command
    main.rs                 ← binary entry: calls pragna2_desktop_app_lib::run()
  Cargo.toml                ← crate: pragna2_desktop_app, lib: pragna2_desktop_app_lib
  tauri.conf.json           ← productName: Pragna2, identifier: com.pragna2.app
  build.rs                  ← tauri-build codegen
```

## 5. Method Specifications

### `lib.rs`

#### `greet(name: &str) -> String`

| Field | Detail |
|-------|--------|
| **Purpose** | Demo Tauri command — returns a greeting string from Rust to the frontend |
| **Inputs** | `name: &str` — the name to greet |
| **Output** | `String` — formatted greeting message |
| **Errors** | None — infallible |
| **Side Effects** | None |
| **Invariants** | Generated by scaffold; to be moved to `adapters/` when first real feature is added |

#### `run() -> ()`

| Field | Detail |
|-------|--------|
| **Purpose** | Initialise and run the Tauri application event loop |
| **Inputs** | None |
| **Output** | `()` — does not return (blocks until window is closed) |
| **Errors** | Panics via `.expect()` if the Tauri runtime fails to start |
| **Side Effects** | Opens the desktop window, registers IPC handlers |
| **Invariants** | Entry point called from `main.rs` |

## 6. Error Handling Strategy

| Error | Layer | Propagation |
|-------|-------|------------|
| Tauri runtime failure | Adapters (`lib.rs`) | `.expect("error while running tauri application")` — fatal panic; acceptable for startup failure |
